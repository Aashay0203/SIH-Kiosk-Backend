🔀 Routes
authRoutes.js /api/auth ▶
Method Path Description
POST /api/auth/signup Registers a new user account and returns JWT token.
POST /api/auth/login Authenticates user or doctor credentials and returns JWT token.
appointment.js /api/appointment ▶
Method Path Description
GET /api/appointment/my-appointments Returns a protected test response with current user id.
GET /api/appointment/booked-slots Returns already booked slots for a doctor on a given date.
POST /api/appointment/book Validates slot and creates a Razorpay order for appointment booking.
GET /api/appointment/my-appointements Returns logged-in patient appointments with doctor details.
GET /api/appointment/:id/status Returns queue position, ETA, and live appointment status.
PUT /api/appointment/:id/arrive Verifies appointment PIN and marks patient as arrived.
doctorRoutes.js /api/doctor ▶
Method Path Description
POST /api/doctor/signup Creates doctor account (admin-only) and returns JWT token.
GET /api/doctor/allDoctors Returns doctor listing with key profile and availability fields.
GET /api/doctor/:id Returns full details for a specific doctor.
healthProfileRoute.js /api/healthProfile ▶
Method Path Description
GET /api/healthProfile/ Returns complete patient health profile.
PUT /api/healthProfile/user-data Saves manual user-provided health information.
DELETE /api/healthProfile/ Deletes patient health profile document.
GET /api/healthProfile/ai-only Returns only the AI-extracted section of the profile.
GET /api/healthProfile/user-only Returns only the user-provided section of the profile.
medicationRoute.js /api/medication ▶
Method Path Description
GET /api/medication/ Returns all medications for the logged-in user.
POST /api/medication/ Creates a new medication record for the user.
PATCH /api/medication/reset-daily Resets the taken flag to false for all user medications.
PATCH /api/medication/:id Updates the taken status of one medication entry.
paymentRoute.js /api/payment ▶
Method Path Description
POST /api/payment/verify Verifies Razorpay signature and finalizes a paid appointment.
POST /api/payment/upi-confirm Confirms UPI payment flow and finalizes appointment with token/PIN.
POST /api/payment/cash-confirm Finalizes cash appointment and reserves slot/token.
queueRoute.js /api/queue ▶
Method Path Description
PUT /api/queue/next Advances doctor queue to next token and marks previous as served.
reportRoute.js /api/report ▶
Method Path Description
POST /api/report/upload Uploads report to Cloudinary, saves metadata, starts AI background processing.
GET /api/report/ Returns all reports for the logged-in user.
GET /api/report/:id/ai-status Returns AI processing state, summary, and AI error for one report.
POST /api/report/:id/regenerate-summary Resets AI state and re-triggers background summary generation.
GET /api/report/:id Returns one report document for the user.
PATCH /api/report/:id Updates report metadata fields.
DELETE /api/report/:id Deletes report from Cloudinary and database.
userRoute.js /api/user ▶
Method Path Description
GET /api/user/profile Returns logged-in user profile (without password).
PATCH /api/user/profile Updates editable profile fields for the logged-in user.
POST /api/user/profile/picture Uploads and updates profile picture via Cloudinary.

⚙️ Services · Jobs · Utils
services/geminiService.js
getGeminiModel Returns Gemini model id from env or default fallback.
fetchFileAsBase64 Downloads remote report file and converts it to base64 with content type.
resolveMimeType Resolves effective MIME type using response header or file extension fallback.
parseGeminiJSON Cleans Gemini response text and parses strict JSON output.
analyzeReport Sends one uploaded report to Gemini, returns structured extracted summary.
buildHealthProfile Sends multiple report summaries to Gemini, returns consolidated profile insights.
jobs/processReport.js
processReportInBackground Updates report AI state, runs Gemini analysis, stores aiSummary, triggers profile refresh job.
jobs/updateHealthProfile.js
updateHealthProfileAI Aggregates completed report summaries, calls Gemini, upserts aiExtracted profile data.
updateHealthProfileManual Upserts user-provided health form data into profile with a completion timestamp.
utils/calculateETA.js
calculateETA Computes remaining queue count and estimated wait from token difference and avg consult time.
🛡️ Middleware
🔑
authmiddleware.js
Verifies JWT token from Authorization header; attaches decoded user to req.user.
🚫
adminOnly.js
Blocks non-admin requests; used to protect privileged routes like doctor signup.
🎭
roleMiddleware.js
Checks req.user.role against allowed roles; returns 403 if access is denied.
